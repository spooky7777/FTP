# Full Throttle Performance launch checklist

This is a project status checklist, not permission to deploy.

## Client facts and content

- [ ] Obtain client approval for name, phone, email, address, hours, domain, social links, and map URL.
- [ ] Replace all starter values in the central client data file.
- [ ] Replace every placeholder meta description.
- [ ] Remove or replace CodeStitch blog titles, authors, and starter content.
- [ ] Confirm service claims, warranties, guarantees, vehicle support, and portfolio permissions.
- [ ] Decide whether to add a contact form or intentionally use phone and email only.

## Technical correctness

- [ ] Run `npm run build` successfully from this repository root.
- [ ] Correct `/assets/Images/` references to match the lowercase source directory.
- [ ] Fix the footer email target and remove empty links.
- [ ] Add a valid absolute social-sharing image.
- [ ] Confirm canonical URLs, sitemap URLs, and robots behavior use the production domain.
- [ ] Verify every local and external link in the generated site.

## Experience and quality

- [ ] Test navigation and content at mobile, tablet, and desktop sizes.
- [ ] Complete keyboard, focus, heading, image-alternative, label, and contrast checks.
- [ ] Replace the multi-megabyte homepage photos and SVGs with optimized responsive assets.
- [ ] Ensure mobile sources are actually smaller than desktop sources.
- [ ] Check the homepage on a cold mobile load and review every third-party asset.

## Release

- [ ] Review the final diff and build output.
- [ ] Confirm analytics and consent requirements, if analytics will be used.
- [ ] Back up or tag the last known-good release.
- [ ] Obtain client approval before deploying or changing DNS.
